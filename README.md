Netflix India Clone is a frontend web development project that replicates the visual design and layout of the Netflix India homepage using HTML5 and CSS3. The project includes a responsive navigation bar, hero/banner section with an email signup form, trending movies section, reasons to join, FAQ section, and footer. CSS media queries have been implemented to make the website adapt to mobile screen sizes.
Features implemented
🎬 Netflix-style hero/banner section
🔴 Netflix-inspired navigation and Sign In button
🌐 Language selector
📧 Email input + Get Started button
🔥 Trending Movies section with numbered overlays
📺 More reasons to join cards
❓ Frequently Asked Questions section
📱 Responsive mobile layout using media queries
🔗 Footer with navigation links
🎨 Netflix-style dark theme and red accents
🖱️ Hover effects on buttons and FAQ items
